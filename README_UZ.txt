TECHYORDAM UZ — ISHGA TUSHIRISH
================================

TALABLAR
- Windows 10
- VS Code (bepul)
- Zamonaviy brauzer: Chrome, Edge yoki Firefox
- Internet faqat tashqi AI xizmatlari va rasmiy dars havolalarini ochish uchun kerak.
  Saytning ichki vositalari internetga ma'lumot yubormasdan ishlaydi.

1. ZIP FAYLNI OCHISH
- TechYordamUZ.zip faylini yuklab oling.
- Fayl ustiga o'ng tugma bosing → "Извлечь все..." / "Extract All".
- Ochilgan TechYordamUZ papkasini tanlang.

2. VS CODE'DA OCHISH
- VS Code'ni oching.
- "Файл" → "Открыть папку..." (File → Open Folder).
- TechYordamUZ papkasini tanlang.
- Chap tomonda index.html, style.css, data.js, script.js fayllari ko'rinadi.

3. SAYTNI ISHLATISH
ENG OSON USUL:
- Papkadan index.html faylini toping.
- Ustiga ikki marta bosing; Chrome/Edge'da ochiladi.

VS CODE BILAN:
- index.html faylini VS Code'da oching.
- Xohlasangiz, "Live Server" kengaytmasini o'rnating (bepul).
- index.html ustiga o'ng tugma → "Open with Live Server".
- Live Server majburiy emas.

4. TIL VA MAVZUNI ALMASHTIRISH
- Yuqori o'ngdagi RU/UZ tugmasi o'zbekcha va ruscha interfeysni almashtiradi.
- ☼/☾ tugmasi qorong'i va yorug' rejimni almashtiradi.
- Tanlovlar shu brauzerda saqlanadi.

5. SAYTNI O'ZGARTIRISH
- AI xizmatlari va ularning tavsiflari: data.js → ai ro'yxati.
- Promptlar: data.js → prompts ro'yxati.
- Darslar: data.js → lessons ro'yxati.
- Kompyuter bo'yicha yo'riqnomalar: data.js → help ro'yxati.
- Dizayn: style.css.
- Tugmalar va funksiyalar: script.js.
- Barcha fayllar bir papkada tursin. Fayl nomlarini o'zgartirmang.

6. INTERNETGA BEPUL CHIQARISH
VARIANT A — GITHUB PAGES:
- GitHub.com saytida bepul akkaunt yarating.
- New repository tugmasi bilan yangi repository yarating.
- Ushbu papkadagi fayllarni repository'ga yuklang.
- Repository → Settings → Pages bo'limini oching.
- Build and deployment qismida Deploy from a branch ni tanlang.
- Branch: main, folder: /(root), Save.
- GitHub Pages havolasi tayyor bo'lishini kuting.

VARIANT B — VERCEL:
- Vercel.com saytiga GitHub orqali kiring.
- Ushbu loyihani GitHub repository'ga yuklang.
- Vercel'da Add New → Project orqali repository'ni import qiling.
- Oddiy statik sayt bo'lgani uchun build command talab qilinmaydi; framework preset kerak bo'lsa Other ni tanlang.
- Deploy tugmasini bosing.

7. MUHIM ESLATMALAR
- Loyiha oddiy HTML/CSS/JavaScript saytidir. Backend, akkauntlar yoki AI modeliga to'g'ridan-to'g'ri ulanish mavjud emas.
- AI vositalari tugmalari ularning rasmiy saytlarini ochadi; ayrim xizmatlar akkaunt, hududiy mavjudlik yoki pullik tarif talab qilishi mumkin.
- "Bepul tarif bor" belgisi xizmatda bepul kirish varianti bo'lishi mumkinligini anglatadi. Limitlar va shartlar o'zgaradi; rasmiy saytdan tekshiring.
- Parol kuchini tekshirish vositasi faqat brauzer ichida ishlaydi. Haqiqiy parolingizni begona saytlarga kiritmang.
- Base64 kodlash shifrlash emas. Maxfiy ma'lumotni kodlamang.
- Ushbu loyiha foydalanuvchi ma'lumotlarini serverga yubormaydi. Til va mavzu tanlovi brauzer localStorage'ida saqlanadi.

XAVFSIZLIK
Tashqi havolalar yangi oynada rel="noopener noreferrer" bilan ochiladi.
Har qanday muhim tizim sozlamasini o'zgartirishdan oldin fayllaringizning zaxira nusxasini saqlang.
